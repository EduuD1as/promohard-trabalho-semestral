# Trabalho Semestral do Curso Técnico em Desenvolvimento de Software - CEDUP Timbó, 2024.

## Promohard

## Resumo:
  A aplicação Promohard surge através de um problema na busca por bons valores, promoções e preços de hardware no mercado de e-commerce do Brasil. Nessa busca, a maioria dos usuários acaba enfrentando alguns problemas, o principal deles é a dependência de um único mecanismo de busca, tendo que navegar em site por site através de opções que possam agradar-lhe.
  Diante dessa situação, nota-se que uma aplicação Web poderia atender essa demanda, resolvendo esse problema e unificando os principais hardwares, em um só lugar. É assim que surge a aplicação Web Promohard, criada para consulta de preços de hardware em um só lugar, com as ofertas dos maiores e-commerces do ramo, KaBuM, Terabyte e Pichau.
